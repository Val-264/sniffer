### Requisitos para clonar y ejecutar el proyecto

* **Plataforma:** Windows 
* **IDE:** Visual Studio (morado) 
* **Dependencia(s) de Visual Studio:** Desarrollo de escritorio con C++

**Instalaciones externas:**
1. **Npcap 1.88 installer for Windows:** Descargar y ejecutar la instalación estándar.
2. **Npcap SDK 1.16:** Descomprimir el archivo descargado y poner todos los archivos resultantes exactamente en una carpeta llamada `npcap` en la raíz del disco duro local (`C:\npcap`).

**Nota de ejecución:** Es estrictamente necesario abrir Visual Studio como Administrador. De lo contrario, el sistema operativo bloqueará el acceso a las tarjetas de red y el programa no podrá capturar tráfico.
